# 守望支线地形与事件（v0.3.0）

v0.3.0把原守望十关分布到Serpulo、Erekir命名主线附近，按主线总星数和锚点普通通关条件开放；具体门槛、五星模式和满星奖励见[五星战役说明](STAR_CAMPAIGN.md)。v0.2.0归档仍保留原来的独立星球与顺序解锁。每关准备180秒后进入计时波次。第一关波间55秒，第二至第四关65秒，后六关75秒。战役允许暂停，也可用波次按钮提前出兵。完成最后一波并消灭存活敌人后占领区域。

## 地形与设施

地图尺寸从144×144增至192×192。每关有弯曲主路、标出的侧翼出生点、核心附近的矿床，以及可选择扩张的前沿矿区。港湾另有海军出生点和连续水道。侧翼出兵时间写在简报与预告中，出生区的禁建范围从开始即可见。

铜、铅各一条基础采矿线送入核心。两座双管炮有启动弹药，短墙留有中央缺口。电力关卡提供燃煤发电机、节点与电池，长期供电仍需补充煤和扩建。

每关提供固定启动物资，后期增加钛、塑钢、钍和少量高级材料。图内有矿床、沙地和取水点，可继续制造弹药。科技按关卡免费开放，同时用建造白名单控制装备范围；课程战役不会把免费科技永久解锁到原星球。

前沿矿区的废弃炮塔、电池可通过原游戏的废弃建筑修复机制利用。清障事件移除矿区前面的自然障碍，并将一批煤和硅送至核心，它不是额外胜利条件。

## 事件如何改变策略

- **侧翼、退潮、快速侧翼**：清除自然关口，第二出生点按新编组出兵，准备另一段阻击线。
- **融冰**：西侧冰面变成浅水，地面单位通行变慢，东侧固定通道可用。
- **洪水**：西侧浅滩变成深水，地面单位改走东桥，既有建筑所在格不会转换。
- **喷发**：西侧通道变为熔渣，同时开放侧翼，东桥保留。
- **沙尘暴**：太阳能倍率降至0.15，四波后恢复原值，燃料发电机可继续使用。
- **电磁停电**：玩家的发电机停机，包括后来新建的发电机。电池不被清空，可维持激光与生产，实弹炮塔仍能使用已有弹药。指定波次恢复由事件停用的发电机，原本手动关闭的发电机仍关闭。
- **空军、海军、集群、装甲与守护者**：按预设SpawnGroup改变敌人构成。空军越过围墙，海军走水道，爬虫要求范围火力，重型单位需要集中输出和维修。
- **补给**：有限物资送进核心，受核心容量限制，没有无限资源模式。

## 预告与保存

核心信息板说明全部关键波次。屏幕上方持续显示下一事件的波次与内容，触发时出现通知。事件在敌人出生前执行，第7波侧翼事件会影响第7波出兵。

已执行事件保存在`Rules.tags`的`watch.event.*`条目；停用发电机使用`watch.power.*`条目记录。地形、建筑状态、波次与事件条目一起进入原生`.msav`存档，读档继续当前进度，不重新发补给。记录只作用于十张守望支线地图；原版主线地图及其他编号区域不会运行这些事件。

## 当前验证范围

自动路线测试把可摧毁的玩家建筑视为可攻击的障碍，验证自然地形没有封死路线。这不等于保证任何布局都能获胜。路线测试也检查海军能否进入对核心的射程。

首版以功能完整为目标。敌人数、守护者强度、物资与波间时间均集中在`WatchCampaign.java`，后续根据真实试玩调整。当前没有人工完成十关全部通关，不把自动测试当作平衡结论。
