# Mindustry v0.3.5 五星战役预览版

官方原版与改版统一放在同一目录，以版本号文件名区分。两份程序均为已有发布程序的副本，游戏代码和版本号未改。

|版本|程序|启动文件|存档|
|---|---|---|---|
|官方原版v160.7|Mindustry-v160.7.jar|Mindustry-v160.7.bat|游戏数据|
|五星改版v0.3.5|Mindustry-v0.3.5.jar|Mindustry-v0.3.5.bat|五星存档|

本机双击对应BAT即可运行。入口优先使用`工具/jdk-17.0.20.1+1`；同目录合集下载包不含JDK，其他电脑需先安装Java17并配置java命令。请保留程序旁的存档目录，移动合集时一并带走。

改版仍包含原版Serpulo、Erekir战役，主菜单“战役”进入原版流程，“五星战役0.3.5”进入五星主线与支线。每关普通最多三星、英雄和战术各一星；只有支线满五星授永久奖励，适用于全部五星主线与支线。

已通过665项回归及必要的原生/桌面验证，当前未发现已确认的通关阻断。41/168种不同历史模式有满分实战记录；完整试玩和整体平衡尚未全部验收，因此保持预览版。本次只调整文件布局，不新增试玩成绩。

原版与改版现有数据、八个历史源码标签和发布附件继续保留。旧`五星战役.bat`转到带版本号的改版入口，`开始游戏.bat`继续用于当前源码构建，`守望十关.bat`继续运行旧v0.2.0。

本机源码位于`Mindustry`和同级`Arc`；本版固定源码：[coursework-v0.3.5](https://github.com/lxy666-qwq/mindustry-watch-campaign/tree/coursework-v0.3.5)。对应Mindustry与Arc源码下载见[发布页](https://github.com/lxy666-qwq/mindustry-watch-campaign/releases/tag/coursework-v0.3.5)。

完整关卡、反制前置及奖励说明：[STAR_CAMPAIGN.md](https://github.com/lxy666-qwq/mindustry-watch-campaign/blob/coursework-v0.3.5/docs/STAR_CAMPAIGN.md)。验证与历史实战范围见同标签的`docs/verification-v0.3.5.md`、`docs/playthrough-v0.3.5.md`。GPL-3.0及上游版权保留，许可证见`LICENSE`和`Arc-LICENSE`。
