# 原版与v0.4.0同目录发行

|版本|程序/启动文件|存档|
|---|---|---|
|官方原版|Mindustry-v160.7.jar / Mindustry-v160.7.bat|游戏数据|
|连续地图五星预览版|Mindustry-v0.4.0.jar / Mindustry-v0.4.0.bat|五星存档|

本机双击BAT即可运行，优先使用旁边工具中的JDK17；下载同目录合集后，其他电脑需安装Java17。原版与改版的存档内容不合并；改版继续原五星存档，最高成绩保留。旧程序仍可选择，当前“五星战役.bat”转到v0.4.0。

进入主菜单“五星战役0.4.0”选择星球即可打开连续绘制地图；原菜单“战役”保留原版流程。[地图操作](ROUTE_MAP.md)。

九个源码版本通过独立coursework-vX.Y.Z标签保留；旧发布及附件不覆盖。本版程序、Mindustry与匹配Arc源码见[发布页](https://github.com/lxy666-qwq/mindustry-watch-campaign/releases/tag/coursework-v0.4.0)。本版673回归和必要UI检查通过，历史41/168种满分实战，完整平衡未验收，保持预览。[验证](verification-v0.4.0.md)。
