## 同档门禁与奖励链

`progression-chain`从此前不存在的设置目录开始，没有复制旧成绩、人工授星或绕过门禁。每次进入均检查原前置、装备要求及挑战普通通关条件。零号普通取得3星；绿谷普通3星时奖励仍关闭，英雄后4星时仍关闭，战术后5星才生效。

独立只读重启读取同一文件，确认零号3／0／0、绿谷3／1／1、主线总3星、绿谷5星、满星奖励为真、冰冻森林门禁为真。证据是`progression-chain/profile-reload.txt`与各步骤结果。它证明这条早期链，未验证其他九条支线或全战役；冰冻森林实际战斗尚待后续记录。

## 任务边界

战术Task A仅计胜利保留的新基础Conveyor／Duct／Conduit：资源实际送出后沿原生交接链进入核心库存、转为有效物品／液体弹药，或由消费者随后实际产出物品、液体或电力。纯闭环、满核心烧毁、闲置生产设施、单纯冷却液及单纯制造单位的工厂不单独提供有效终端。桥、路由、卸载器和质量驱动器保留真实方向；交叉器按资源及直行通道分离；中转建筑本身不计基础运输数量。

至少一次有效供给即可，不强制持续吞吐或净库存增长。因此目前核心卸载→新带→返还核心也可计；仍须完成Task B两座真正新建、胜利保留、最后60秒真实产出／发电的设施，以及胜利、核心保护和预算。这个回流边界仍需后续平衡核查，不能宣称所有省力策略已排除。

身份、实际交接边和消费者输入证据保存到任务标签，空运沿用身份，SaveIO后重建关系。旧任务若无`flowVersion`，只清旧单次输送标记，需新版有效供给重新确认；已获永久最佳星保留。

晶石要塞原图没有矿渣地板或废料，初始库存无巨浪合金，单纯解锁劫难不能就地产出100合金造价。仅雷暴高地满五星后，晶石要塞新开的普通／英雄／战术任务各提供一次100合金有限建造包，续档不补发；其他材料、热量、供电和弹药仍按方块规则准备。它是该图有限例外，原生基地不获得它。
