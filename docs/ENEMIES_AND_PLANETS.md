# 裂殖运兵车与星球门槛

## 裂殖运兵车

v0.6.0新增独立单位 `watch-brood-carrier`，使用橙色履带运兵车贴图。生命420、护甲4、移动速度0.65；单门武器伤害12、60逻辑帧一发，只攻击地面，弹速2.5、寿命30逻辑帧。

- 双峡隘口、雷暴高地、终末堡垒的部分装甲遭遇中，各只出现一辆；游戏不提前公开对应事件的触发时刻。
- 替换该波原来的一辆装甲单位。后续装甲波仍使用原配置，不额外叠加原装甲单位。
- 死亡使用原生 `SpawnDeathAbility`，只放出两只普通爬虫；爬虫不具有该能力。敌人总量有限，不递归、不回血、不召唤运输车。
- 遭遇实际发生后提示：石墨弹／激光先破甲，火焰／电弧清理爬虫。双峡已开放石墨压缩机、火焰和电弧，后期关卡继续具备这些基础反制。
- 飞行单位不受运输车主武器攻击。运兵车不提供新的永久奖励，也不改变满星支线奖励规则。

父车及两只爬虫的合计威胁高于只看车体420生命的估计，不能据单体生命就认定更弱。游戏只用环境渐变呈现前兆，出现后再说明反制；后期保留高阶重甲敌人。实际通关与平衡结果单独记录，不以专项测试代替。

## Erekir解锁

新档需取得 **15颗Serpulo命名主线星**，才能点击Erekir星球卡。普通、英雄、战术星均可计，守望支线星不计。Serpulo始终开放，因此解锁成本不依赖锁内成绩。

只要旧档已经有任意Erekir主线或其守望支线的真实成绩，继续保留该星球访问权。已有占领主线通过原有兼容规则计普通1星；不追加新成绩、不删除奖励。原版星球界面和普通原生战役不使用此门槛。

新增测试分别验证新档、支线不支付门槛、旧档保留和门禁图的可达容量。图测试中临时授星只是独立测试夹具，结束后还原；这项测试不计入实际试玩、正常流程解锁或通关台账。
