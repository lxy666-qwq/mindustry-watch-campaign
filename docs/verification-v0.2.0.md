## 回归中修正的问题

- 程序生成关卡起初共用了空地图元数据，造成上游校验以0×0加载关卡。改为每关独立Map对象，带实际尺寸，避免改写其他关卡的元数据。
- 上游校验原先按Serpulo/Erekir两种星球硬编码敌方阵营。现在检查各星球自己的`ruleSetter`，仍验证关卡符合星球规则。
- 港湾增加可接近核心的南侧船坞水道，验证海军具有攻击条件。
- 守望HUD显示实际完成波次和本关总波数，内部胜利阈值仍遵循原引擎下一波计数方式。
