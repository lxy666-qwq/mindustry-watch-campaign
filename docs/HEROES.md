# 守望哨兵

0.5.0第一项改进：可操控的支援角色。双峡隘口满五星永久解锁部署台，作用于五星战役的主线和支线。主线取得星数不发放本奖励。

- 部署台：铅60、硅40，2×2，生命260。
- 点击部署台，再点击“部署并接管”，消耗核心石墨40、硅30。每次任务一次，不可免费复活。
- 单位：生命180、速度2.2、采矿速度4、建造速度0.35、容量20。机动和生产能力低于阿尔法，控制沿用原版单位。
- 迟滞弹：伤害6，只打地面单位，不伤建筑。150逻辑帧一发，减速60逻辑帧。正常60帧逻辑下分别为2.5秒和1秒。
- 次数记在任务Rules.tags。多台、拆建、单位死亡或装入载荷均不补发；保存读取沿用同一标记，新开任务才有新次数。
- 原版战役、编辑器、PVP和联机不可部署。没有新增必须依靠英雄的关卡前置。
- v0.5.0基础机体与图标沿用阿尔法并追加护甲。v0.6.0替换为独立青绿支援机PNG，机体、预览和单位图标均使用该图；未增强原有战斗参数。[美术文件与生成说明](ARTWORK_UNITS.md)。
