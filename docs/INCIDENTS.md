# 突发状况与环境前兆

v0.6.0为46个官方命名主线各配置一项突发状况，守望10条支线保留原有37项地图/波次变化。共56关，普通、英雄、战术均使用各关自己的事件。此处说明机制，不列未来事件的关卡时间表。

## 如何发现变化

发生前，游戏不显示事件名称、波次、倒计时、效果或未来事件列表。地图与背景只逐渐出现与当前地貌相符的薄雾、浮尘、微光和粒子：冰原偏冷白、沿岸偏青蓝、孢子地带偏紫、火山地带偏赤橙。它们只是环境前兆，不提前改变通路、供电、材料或敌人。

状况实际发生后才弹出通知，并在任务HUD显示当前状态。主线右上角出现“处置当前状况”按钮，可阅读实际影响、作出选择或定位当前标记。定位只移动镜头，不自动移动单位；对话框不强制暂停战斗。守望已发生事件的说明会短时留在HUD，正在停电时保留供电状态提示。

关卡简介只描述眼前地形，不再写未来事件时间表。原生下一波倒计时仍属于普通波次界面，不显示其中是否包含事件。

## 五种主线机制

|机制|实际操作及效果|边界|
|---|---|---|
|分批回收|控制单位在金色标记附近连续驻留5秒，依次回收3批，每批20铜/铍和8石墨|总计最多60基础矿物及24石墨；150秒窗口；离开重计驻留；放弃不扣星|
|驻留中继|驻留10秒接通；施工速度临时+25%，持续45秒|接通前有120秒操作窗口；只加快施工，材料费用、伤害、生命与星级条件不变|
|地勤取舍|支付30铜/铍调来工兵，施工+25%/45秒；或接收25铜/铍和10石墨|只可选择一次；不抽调材料就没有工兵加速；仅本任务有效|
|调度窗口|施工+15%、已有单位制造+20%，持续55秒|正常消耗材料；不会免费生成单位；不会改变单位伤害、生命或单位上限|
|短时干扰|施工-10%、单位制造-15%，持续35秒；可支付20铜/铍立即解除|不断电、不减炮塔伤害、不删库存；可以靠现有防线等待结束|

回收和中继在核心周围4—13格内挑选已发现、无建筑、可站立的地面，并避开敌方核心邻近区域；若原教程基地没有合适空地，则在核心位置办理。不会要求进入危险液体、未知地带或先拥有支线英雄。三个回收方向分别挑选，不改地形也不强占建筑。

工兵加速与制造窗口分别作用于原生队伍施工/单位制造倍率。到期恢复进入窗口前的值；如果原世界处理器期间自己改变了相应倍率，保留该处理器的新值，不把剧情状态回滚。任务结算时清理仍在生效的临时倍率。

## 与原地图和存档的关系

防守主线在波次推进中进入状况；原生攻坚/教程图使用任务已进行时间。确切触发点属于开发配置，不在游戏中预告。不改原地图的处理器、剧情旗标、攻防阶段、原生目标或胜利条件。

事件状态保存在本次任务的Rules.tags中：开始、结束、是否已经选择、回收批次、驻留进度、标记位置、倍率原值及到期时间。读档继续同一状态，不重发已经领取的物资。新开任务允许重新经历事件；这不是全局奖励。永久能力和装备仍只有支线满五星才能获得。

旧版已经进行中的官方主线继续原有流程，避免读档瞬间插入无前兆事件；用v0.6.0重新开启主线后启用新状况。原版战役、编辑器、PVP及联机不启用这套主线事件。

## 实现与当前状态

- `core/assets/campaign-incidents.json`：46关独立配置与中英场景文字。
- `CampaignIncidents.java`：触发、选择、驻留、物资、临时效果、保存状态、事后按钮及无文字环境前兆。
- `WatchCampaignEvents.java`：守望原有变化，去掉未来事件HUD，加入无文字前兆与事后说明。

按用户最新要求，本轮暂停自测、试玩和已完成任务复查，只编译打包。这里记录实现规则，不宣称新事件已通过运行或平衡验收。
