# 守望第六关：反制装备只读核对

核对范围：2026-10-13 当前源码及固定 v0.3.2 `branch032-runtime/Mindustry.jar` /完整资产；不修改产品、不授星、不改库存。以下区分源码行为与真实战斗记录。当前独立 W6 普通仍仅两星，英雄/战术未授星；不能据此判定全奖励条件下不可通关。

## 解锁和材料是两个条件

`CampaignProgression.rewardSet(4, false)` 给第五支线满5后的 Serpulo 装备是 Swarmer/Segment。`requiredReward` 对所有守望支线返回 -1，因此 W6 当前不强制 W5 满5；它的主线星数及锚点条件也不自动证明 W5 五星。

原生 Segment 建造需求是硅130、钍80、相织布40、钛40（`Blocks.java:3858`），不是巨浪合金。W6 默认设备没有 Segment，获得 W5 奖励后规则能放开建造，但现有 W6 初始物资不含钍/相织布：

- `WatchCampaign.java:243` 起始硅300、钛350、塑钢250，钍/相织布到 level>=7 才加入。
- `WatchMapGenerator.java:141` 钍矿到 level>=7 才绘制；W6 的前进矿点是钛。其他资源点是铜、铅、煤、沙，没有废料供分离器取得钍。
- `WatchCampaign.java:206` 相织布合成机到 level>=8 才开放。W6 没有该生产链。
- W6 波次事件只有第8波海军、第13波低潮、第21波首领，没有物资补给；其他关卡补给事件也只发铜/石墨/钛或煤/硅。

所以 **原生 Segment 即使已研究解锁，现版本 W6 仍没有合法材料路径**。这是一条可复现的装备可建设性缺口，不是对所有普通战斗策略难度的结论。Tsunami 同样需要钍100、钛250，W6 默认虽开放它，钍仍不可取得。

## 原生 Segment 对 Bryde 做了什么

`UnitTypes.java:1737`：Bryde 主炮是 ArtilleryBulletType，基础直接伤害15、溅射70、半径40世界单位（5格），`collidesTiles=false`。原生墙体不能阻挡其落点炮击。导弹基础直接伤害12、溅射10、半径25。

`BulletType.java:151` 默认 `hittable=true`，上述炮弹没有覆写。`PointDefenseTurret.java:66` 选择敌方 hittable 弹丸；Segment 单次削减30，装填8帧、范围180、耗电8/帧。Boss伤害×1.3，英雄规则再×1.15，两种 Bryde 弹丸直接伤害仍小于30，可在一次拦截中移除弹丸。

但移除不是无伤吸收：`PointDefenseTurret.java:90` 调用 `target.remove()`；`BulletComp.java:83` 继续 `despawned`；`BulletType.java:845` 因存在溅射使 `despawnHit=true`，在截击点引爆。`BulletType.java:607` 只有 `b.absorbed` 才阻止溅射，而这里没有调用 `absorb()`。溅射倍率由 owner 与规则决定（`BulletType.java:547`），不由拦截后的剩余直接伤害决定。

因此 Segment 可以让炮弹提前引爆，需要在核心朝海的一侧布置并保持拦截点距核心超过5格；贴近核心或来弹拥塞时仍可能伤核。它不是无条件让主炮伤害消失的能力。未来有限配给方案必须真实验证供电、旋转、来弹数量、爆点及核心最低生命，而不能只测塔已建设或弹丸已移除。

## 现有战斗证据和后续最小方案

固定 v0.3.1 普通21：24波真实胜利、147次建设、21座损失，核心最低47.74%，只获两星。`core-damage.csv` 有 Bryde 的21条核心伤害和末波 Minke 的4条伤害。Bryde 预定第21波出现；生成后原生 `state.wave` 已递增为22，不能把该计数当波次设计被更改。

前排普通24真实失败：浪涌炮未完成时被地面火力破坏，重建消耗初始钛，最后核心被首领摧毁。这证明该部署失败；不是无反制证明。已有普通胜利、原生工厂/采矿机、炮塔接管和其他可用生产设备仍应继续研究。

若产品要保证 W6 有原生拦截反制，最小候选是：W5 五星真实奖励后，在每次 **新建 W6 任务** 加一份有限 Segment 配给（硅130、钍80、相织布40、钛40），并让读档继续沿用持久标签而不补发。数量只能保证造一座，不改变伤害、敌人、胜利和判星规则。是否将 W5 满5加入 W6 前置，应根据关卡树可达性单独核对；现有门槛不能被描述成已包含这个前置。此方案尚未实现或试玩，不登记为通过。

较少侵入的战术候选：原生 Wave 水流减速/击退配合炮击，真实 NavalFactory+Risso生产（需先补玻璃链），提前建设更靠海的炮位；两座 WaterExtractor 在核心附近供水，可成为 NAVAL 战术的两座新泵，减少前方水泵被炮击后无法完成近60秒任务的风险。WaterExtractor 的原生基础效率为1，可在固体地面实际产水，成本为玻璃30/石墨30/铅30/铜30，不消耗硅。所有候选仍需通过真正的战斗和终端供给验证。
