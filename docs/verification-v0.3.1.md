# v0.3.1 验证记录

记录日期：2026-10-13。修订范围是五星任务的核心最低生命记录；完整战役仍为预览版。

## 问题与验收条件

v0.3.0仅监听弹丸伤害事件并在帧更新时采样。火焰使用原生`Building.damage(float)`，该路径不发弹丸事件；若核心在同帧修复，采样可能漏掉最低生命。独立复现中，核心先降至84.9%、立即修复到100%，旧记录仍为100%。该复现没有胜利或授星。

验收条件：原生核心生命变更时立即记录；同帧修复不能抹去最低值；普通70%、英雄85%、战术60%的门槛使用该记录；SaveIO存读档保持记录；敌方核心、友方普通建筑、非五星任务与已结算任务不改变本次评分。

修复将记录移到原生`BuildingComp.healthChanged()`，仅在进行中的单机五星任务对玩家阵营核心生效，去掉旧的重复弹丸事件监听。帧采样仍保留，用于世界逻辑直接修改生命的情况。

## 实战与版本边界

截至本轮台账，历史及新增合计21/168个不同模式有原生操作脚本的真实授星样例。新增包括洪泛英雄、赤沙三模式与冰冻森林三模式。共享进度真实推进零号普通3→绿谷3/1/1→冰冻森林3/1/1，并由独立重启确认主线8星与绿谷满5奖励；其他独立样例没有合并成绩。冰冻森林英雄、战术明确在v0.3.1运行，普通也随后以2779.2834游戏秒、95.9091%核心最低生命完成新版三星复测；三模式均有本修订的同档实战证据。重复通过不增加覆盖数。始发教程尝试仍未通关，原生headless指挥目标自动通过的边界如实列在台账。

这不是全168任务通关结果。正常桌面人工连续玩法、后续共享满星奖励链和完整难度平衡尚未完成；脚本战斗、自动测试、UI合成检查分别记录。历史v0.3.0成功成绩不能自动改称新版本复测；详见[逐项台账](playthrough-v0.3.1.md)。

已有最高成绩继续保留。旧任务存档无法补回过去漏记的血量变化，新程序从继续运行时记录后续变化。若要重新核对某次挑战，应开新任务。

战术任务仍要求至少一次真实终端供给，未要求持续流量或核心净增量；核心卸载后回流可计的边界继续列入实战平衡核查。本修订只修正已复现的核心生命记录，不认定全部偷懒策略已排除。
