# Mindustry：五星战役与守望支线

基于 Mindustry v160.7，把官方命名主线改为“普通三星＋英雄一星＋战术一星”的五星战役，并将原守望十关分布为主线附近的星数支线。保留原地图目标、地形与产线建设，通过核心保护、限时防御和设施任务增加重玩挑战。

当前版本：**0.3.4（预览版）**。46个官方主线与10个守望支线，各有3种任务，共168个任务、280星。全168个任务的实际通关与难度平衡验证尚未完成。 当前实际满分样例32/168，记录见[v0.3.4实战台账](docs/playthrough-v0.3.4.md)；v0.3.3发布时26项快照保留。装备研究、地图材料和运行产线另见[反制材料审计](docs/counter-material-audit-v0.3.3.md)。

原项目作者为 Anuken 及 Mindustry 社区；本仓库是课程实践的派生版本。原说明保存在 [README.upstream.md](README.upstream.md)。

## 开始游戏

Windows 本地完整环境位于 `D:\软件工程`：

1. 新版入口为 `五星战役.bat`，使用独立的 `五星存档` 目录。
2. 主菜单点击 **五星战役 0.3.4**，选择 Serpulo 或 Erekir。
3. 选择主线关卡，阅读任务要求后开始普通任务；普通通关后可选择英雄与战术挑战；指定关卡还须满足支线满五星装备准备。
4. 主线取得的总星数满足支线门槛，且完成锚点普通任务后，开放附近守望支线。
5. 每次从任务入口开始都从初始地图重玩；通过读档可继续同一次任务。退出前正常保存。

`守望十关.bat` 固定运行 `版本归档\v0.2.0\Mindustry.jar`，继续使用原来的 `守望存档`。旧程序与旧存档单独保留；原版程序与资料位于 v0.1.0 归档。

源码构建的当前程序需要 Java 17，可运行 `java -Dnodiscord -jar Mindustry.jar`。版本号来自 `core/assets/watch-version.txt`。开发版本的构建、验证与发布状态分开记录，不把历史发布包当作当前开发包。

## 每关五星

| 模式 | 星数 | 目标 |
|---|---:|---|
| 普通 | 最多3星 | 完成原图目标1星；全程不失去核心再得1星；核心最低生命始终≥70%再得1星 |
| 英雄挑战 | 1星 | 更强敌军、更短波间；完成原目标，全程核心≥85%、无核心损失，并满足本关时限与建筑损失上限 |
| 战术挑战 | 1星 | 较强敌军、不同附加任务；完成原目标，全程核心≥60%、无核心损失，在建造预算内完成新增物流与实际生产设施要求 |

参与范围为 **Serpulo 29个命名科技主线＋Erekir 17个命名主线**，共230星。普通编号区域与三个无科技主线节点的投稿预设保留原状。原版已占领主线可计普通1星；取得2、3星需要完整记录的任务过程。重玩保留最高成绩，不扣除已有星数。

五星任务创建独立的普通存档，原版扇区基地与占领存档保留。任务的核心受损、建造数量、生产记录、时限与守望事件随存档继续，读取同一次任务不会重复发补给。v0.3.2把大型物流与建筑台账存为独立块，旧任务档可读取；新档请使用本版或后续版本继续。

战术物流只计胜利时保留的新基础带／管：资源须沿实际交接链进入核心库存、有效弹药塔、真正消耗冷却液的炮台，或供给随后真实产出／发电的设施。收入核心还须有真实物品产出或玩家实际投放来源；核心卸载回流不计，合流不能借另一矿源给纯回流支路授分。核心送弹药或真实生产仍可计；至少一次有效供给即可，正常人工搬料允许。炮台须由自己的原生冷却消费者实际用液，闲塔灌水不计；空管、闲置生产线和无终端的物流闭环不计数。两座新增生产设施须在胜利前60秒内有真实产出／发电；搬运原图工厂仍不算新增。旧五星任务读档后重新确认终端供给，已取得的最高星级保留。

逐关挑战档位、时限、预算和评分条件见 [五星战役完整说明](docs/STAR_CAMPAIGN.md)。

## 守望十条支线

潮汐港湾三种模式另需赤沙驿站满五星，先取得裂解拦截装备。支线解锁累计主线关卡的普通、英雄、战术星数；支线所得星数不计入门槛。除星数外，还须完成表中锚点的普通任务。支线在任务列表中紧接锚点显示，在星球上选择附近空闲格；已有预设和玩家基地不被覆盖。

| 赤沙驿站 | Serpulo／焦油田 | 50 | 22 | 沙尘暴、侧翼、守护者 |
| 潮汐港湾 | Serpulo／风吹群岛 | 65 | 24 | 海军、退潮、海军守护者 |

十张守望地图保留37个波次事件、基础采矿线、启动物资和按关卡开放的装备。Erekir上的守望支线继续使用守望装备环境，原版Erekir主线维持其原有地图环境。洪水、喷发保留绕行路线，停电不清空电池，已触发事件存读档后不会重复执行。

预置发电机、节点和电池显式连接，按原游戏电网机制充放电。关卡树与任务说明自动换行，完整显示时限与装备条件。

地形、设施与事件效果见 [守望地图说明](docs/CAMPAIGN.md)。官方原版设置见 [v160.7详细关卡总览](docs/ORIGINAL_CAMPAIGN.md)，含95个预设地图的原参数与世界处理器脚本。

## 关卡树与装备准备

“关卡树”列出原科技主线、额外占领前置、支线锚点和主线星数门槛。部分较难主线还要求先把指定支线打满五星，获得对应的防空、液体防御、储能或维修装备；条件在关卡详情中完整显示，选中英雄／战术时同步更新。

例如零号地区普通通关并达到3主线星后可进入绿谷前哨；绿谷前哨满五星后获得分裂和战地绷带塔，再开放冰冻森林的五星任务。Erekir奖励采用其自身装备环境。终末堡垒只作为起源、行星发射终端英雄／战术的额外准备，两个终点的普通任务不会被它阻塞。完整关系图及十条装备对应表见 [关卡树与装备准备](docs/STAR_CAMPAIGN.md#关卡树与装备准备)。

## 满五星的有限永久奖励

永久奖励只由支线满5星解锁。主线普通、英雄、战术取得任何星数都不授予永久奖励；主线星数只用于评分和解锁支线。全部奖励合计最多建造速度＋8%、拆除返还率＋10个百分点；重复通关不叠加第二份。后勤启动物资为基础矿物80、第二种矿物50、燃料／石墨50，仅新普通任务发放，英雄与战术不发，读档不补发。潮汐港湾在赤沙满五星后，新开的三种任务一次提供钍80/相织布40，供一台裂解的稀缺材料；其硅、钛和电力仍正常准备，仅此图生效且读档不补发。晶石要塞有一项专用有限建造包：雷暴高地满五星后，该图新开的三种任务均给100巨浪合金，供建造劫难；仅该图生效，读档不补发。奖励全局用于五星战役所有主线和支线的三种模式；原生战役基地保持原有规则。

第一条支线 **绿谷前哨满5星**还解锁 **战地绷带塔（Field Bandage）**，可在两个星球的五星任务中建造：

- 建造成本统一为50石墨、40硅，2×2格，生命280。
- 范围8格；友方墙体生命≤30%时，每次消耗2石墨并要求0.7供电，恢复该墙最大生命的15%。
- 同一位置或同一墙体身份共享60秒冷却；多塔、拆建、移动原墙或读档不能刷新这段冷却。
- 只治疗友方墙体，不治疗核心、炮塔、绷带塔本身或敌方墙体。

后勤奖励不调整基础攻击、最大生命或射程。绷带塔提供有材料、电力和共享冷却限制的应急修复；完整关卡难度仍需实战验证。十条奖励的具体对应关系见 [五星战役说明](docs/STAR_CAMPAIGN.md)。

## 从源码构建

依赖：JDK 17、Gradle 9.3.1。Windows 本地工具位于 `D:\软件工程\工具`；匹配的 Arc 位于源码同级 `../Arc`，使用 v160.7 固定依赖配置。

历史发布页提供 `Arc-source-v160.7.zip`。解压后保持同级 `Mindustry/` 与 `Arc/` 目录，可使用本地复合构建。

在本地完整目录运行 `编译源码.bat`、`运行测试.bat`，或：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ..\项目操作.ps1 -Action build
powershell -NoProfile -ExecutionPolicy Bypass -File ..\项目操作.ps1 -Action test
```

普通源码环境使用 Gradle Wrapper：

```bash
./gradlew desktop:dist
./gradlew tests:test
```

构建产物为 `desktop/build/libs/Mindustry.jar`。依赖下载需联网；游戏本地运行无需联网。
